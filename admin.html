COYLI PARFUM · Каталог

Редактирование товаров · доступ к публикации через ваш GitHub
Как работает: отредактируйте товары, нажмите «Скачать catalog.json» и замените файл с таким названием в вашем закрытом репозитории GitHub. Netlify обновит сайт автоматически. Эта страница сама ничего не публикует.

Товар

Для новой фотографии сначала загрузите её в GitHub рядом с index.html, затем впишите здесь точное название файла.

Важно: страница редактора не защищена паролем, поэтому не размещайте в ней секретные данные. Изменять опубликованный каталог может только тот, у кого есть право записи в репозиторий GitHub. Для полноценной приватной панели с входом понадобится отдельная авторизация.
